# Changelog

All notable public changes to Electribe ES-1 Bridge will be documented here.

## [1.0.0] - 2026-10-13

### Added

- First public release under the Electribe ES-1 Bridge name
- Bidirectional MIDI/NRPN control between Korg Electribe ES-1 and Max for Live
- Part View selector
- Support for Part 1–5
- Support for Part 6A / 6B
- Support for Part 7A / 7B
- Support for Slice
- Pitch / Speed control
- Filter control
- Level control
- Pan control
- Per-part Effect On / Off
- Per-part Reverse On / Off
- Global Effect Type control
- Effect Edit 1 control
- Effect Edit 2 control
- Global Delay Depth
- Global Delay Time
- BPM Sync
- Hardware → Max feedback
- Custom presentation-mode interface
- Documentation, troubleshooting and release workflow

### Changed from the original Full Kontrol concept

- New interface and presentation layout
- Direct modernized bidirectional MIDI/NRPN handling
- Updated receive-side feedback logic
- Simplified deployment without the original MIDI-OX mapping workflow
- New documentation and release packaging
