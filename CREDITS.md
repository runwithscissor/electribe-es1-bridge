# Credits & provenance

## Electribe ES1 Full Kontrol

Electribe ES-1 Bridge is based on and substantially reworks:

**Electribe ES1 Full Kontrol v1.25**  
Author: **okan**  
Published: **June 28, 2010**  
Platform: **maxforlive.com**  
Original device type: **MIDI Effect**  
Original license as displayed by maxforlive.com: **AttributionNonCommercial**

Original page:
https://maxforlive.com/library/device/335/electribe-es1-full-kontrol

The original project described itself as a MIDI control patch for the Korg Electribe ES-1 and used MIDI-OX plus a virtual MIDI port to map outgoing CC messages to ES-1 NRPN messages.

The original author also credited **cooptrol** for the idea.

## Electribe ES-1 Bridge

Electribe ES-1 Bridge retains the original project's core goal—controlling the ES-1 from Ableton Live—but substantially reworks the implementation and user experience.

The current project adds:

- a redesigned presentation interface;
- bidirectional hardware ↔ Max feedback;
- direct NRPN receive/transmit handling;
- updated routing logic;
- modern Ableton Live 12 / Max 8 workflow;
- removal of the original MIDI-OX mapping requirement;
- Part View;
- updated Effect and Delay handling;
- documentation and troubleshooting;
- a frozen single-file distribution workflow.
